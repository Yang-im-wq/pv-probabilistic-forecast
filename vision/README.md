# vision/ —— 视觉模块（云检测 + 云量对接）

> 这是「视觉 × 能源」交叉的视觉半边：从天空图 / 卫星云图里把"云"检测出来，算出**云量**，再喂给数值预测模块（LSTM 概率预测）。数值半边在项目根目录，两边通过 `data/merge_cloud.py` 打通。

## 目录结构

```
vision/
├── cloud_detect.py    # 方法一：颜色阈值法（无监督基线）
├── unet.py            # 方法二：U-Net 深度分割模型
├── train_seg.py       # 训练 U-Net（自带合成数据 demo，CPU 可跑）
├── data/              # 输入图片（天空图 / 卫星云图）
├── output/            # 输出（云掩膜、云量、训练结果图）
└── README.md          # 本文件
```

## 两种云检测方法

| | 方法一：颜色阈值法 | 方法二：U-Net 深度分割 |
|---|---|---|
| 文件 | `cloud_detect.py` | `unet.py` + `train_seg.py` |
| 原理 | 云偏白（低饱和+高亮）、天空偏蓝（红蓝差大） | 编码器-解码器 + 跳跃连接，输出云概率图 |
| 需要训练 | 否 | 是（但 CPU 几分钟即可） |
| 精度 | 基线，白色地物会误判 | 更高，可到 IoU ~0.80+ |
| 适用 | 先跑通、快速看云量 | 真实部署、追求精度 |

### 方法一：颜色阈值法

```bash
python vision/cloud_detect.py
```

读取 `vision/data/` 下的图片，输出每张的云量 + 三面板可视化（原图/分割/叠加）到 `vision/output/`。

### 方法二：U-Net

```bash
python vision/train_seg.py
```

用合成天空图做 demo 验证（CPU 约 1 分钟），输出验证 IoU/准确率 + 预测掩膜对比图。

**换真实数据**：只需把 `train_seg.py` 里的 `make_data` 换成真实数据源（SWIMSEG 天空图 + 掩膜，或 FY-4A 云图 + CLM 云检测产品），模型结构 / 训练 / 评估 / 可视化全部复用。

## 云量 → 光伏预测（对接）

视觉模块产出云量时间序列后，只需两步就接入数值预测：

1. 把云量存成 `data/raw/cloud_cover.csv`（两列：时间、云量 0~1）；
2. 正常跑 `python train.py --mode quantile`。

`data/merge_cloud.py` 会自动把云量对齐到 15 分钟时间轴、合并成 `CLOUD_COVER` 特征。**没有真实云量时**，它会用「晴空指数」从辐照度反推一个占位云量，保证链路随时能跑通。

## 为什么云量有价值（讲给老师用）

本地辐照度只能反映"已经压在电站头顶的云"；卫星云量能提前看到"还没飘到电站上空的云"，是光伏爬坡/骤降的**前兆信号**——这正是超短期概率预测最需要、而纯本地气象给不了的信息。
