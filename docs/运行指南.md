# 运行指南：从零开始跑通全流程

本指南覆盖「装环境 → 下数据 → 跑训练 → 出图」的完整命令序列。所有命令在**项目根目录**下执行。

---

## 0. 环境要求

- Python ≥ 3.8（推荐 3.9+）
- 无需独立 GPU，CPU 即可跑通（自动检测 GPU，有则加速）
- 已在 Python 3.8.5 + PyTorch 2.4.1 (CPU) 上验证通过

---

## 1. 装环境

```bash
# 建议先建一个虚拟环境
python -m venv venv
# Windows 激活：
venv\Scripts\activate
# macOS / Linux 激活：
# source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

---

## 2. 下数据（四选一，推荐①）

### 方式一：国家电网（推荐，国内直连、可引用）

1. 用 GitHub 镜像下载站点 1（figshare 官方出处部分网络会 403）：
   ```bash
   curl -L -o data/raw/solar_station_1.xlsx \
     "https://raw.githubusercontent.com/Bob05757/Renewable-energy-generation-input-feature-variables-analysis/main/data_original/solar_stations/Solar%20station%20site%201%20(Nominal%20capacity-50MW).xlsx"
   ```
   （仓库 `data_original/solar_stations/` 下还有另外 7 个电站，可自行下载替换）
2. `config.py` 已默认 `DATA_SOURCE = "state_grid"`，直接运行（无需 `--synthetic`）：
   ```bash
   python train.py --mode quantile
   ```

> 该数据来自国家电网 2021 年新能源预测竞赛，发表于 Nature《Scientific Data》，CC BY 4.0。

### 方式二：Kaggle 真实数据（需 token）

```bash
# 1) 安装 Kaggle CLI
pip install kaggle

# 2) 配置 API token（一次性）
#    打开 https://www.kaggle.com/settings/account → Create New Token
#    把下载的 kaggle.json 放到  ~/.kaggle/kaggle.json
#    （Windows 即 C:/Users/<你的用户名>/.kaggle/kaggle.json）

# 3) 下载并解压到 data/raw/
kaggle datasets download -d anikannal/solarpowergeneration -p data/raw --unzip
```

### 方式三：手动下载

打开 <https://www.kaggle.com/datasets/anikannal/solarpowergeneration> → Download → 把 4 个 CSV 解压到 `data/raw/`。

### 方式四：合成数据（无需联网，先跑通流程）

无需下载任何东西，后面所有命令加上 `--synthetic` 即可，程序会自动生成一份结构一致的合成数据。

---

## 3. 跑训练

```bash
# 点预测基线（阶段 1，可选但建议先跑，作为对照）
python train.py --mode point --synthetic

# 分位数概率预测（阶段 2，核心）
python train.py --mode quantile --synthetic
```

> 用真实数据时，去掉 `--synthetic`：
> ```bash
> python train.py --mode quantile
> ```
> 程序会自动检测到新数据并重建预处理缓存（无需手动删缓存）。

训练过程会打印每个 epoch 的训练/验证损失，并把最佳 checkpoint 保存到 `results/checkpoints/`。

---

## 4. 评估（算指标）

```bash
python evaluate.py --mode point --synthetic      # 输出 RMSE / MAE / nRMSE
python evaluate.py --mode quantile --synthetic   # 输出 RMSE / MAE / PICP / PINAW / CRPS
```

指标同时写入 `results/metrics_point.json` 与 `results/metrics_quantile.json`。

---

## 5. 出图

```bash
python visualize.py --mode point --synthetic
python visualize.py --mode quantile --synthetic
```

生成的高分辨率图（300 dpi）在 `results/figures/` 下：

| 文件 | 内容 |
|---|---|
| `prediction_interval.png` | 预测区间图（核心） |
| `volatile_day.png` | 典型波动日放大图 |
| `scatter_quantile.png` | 预测值 vs 真实值散点图 |

## 6. 一条龙（合成数据）

```bash
python train.py --mode point --synthetic && \
python train.py --mode quantile --synthetic && \
python evaluate.py --mode point --synthetic && \
python evaluate.py --mode quantile --synthetic && \
python visualize.py --mode point --synthetic && \
python visualize.py --mode quantile --synthetic
```

## 常见问题

**Q：训练时提示找不到数据？**
按第 2 节任一方式获取数据，或加 `--synthetic`。

**Q：改了 `config.py` 的超参（如窗口长度）没生效？**
预处理缓存 `data/processed/dataset.npz` 会记录窗口/步长，参数不一致会自动重建；如仍异常，手动删除该文件再跑即可。

**Q：中文在图上显示成方框？**
Windows 一般自带微软雅黑/黑体，会自动使用；Linux 需安装中文字体（如 `Noto Sans CJK`）。

**Q：想换预测目标（如 DC_POWER）？**
改 `config.py` 里的 `TARGET_COL`，并确认它在 `FEATURE_COLS` 里即可。
